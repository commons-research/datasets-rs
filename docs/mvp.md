# Project MVP

## Goal

Demonstrate datasets hosted in large public repositories can be:
- discovered
- structurally inspected
- scientifically labeled
- indexed
- searched by actual content

## MVP Scope:

| Axis | MVP |
|---|---|
| Repository/source | Hugging Face + Zenodo |
| Artifact structure | Tabular + JSON |
| Scientific label | SMILES + molecular formula |
| Search | Inverted index + programmatic query + minimal web/search surface |
| Validation | Existing SMILES and molecular-formula parsers where possible |
| Test source | Real bounded datasets plus deterministic local/mock fixtures |
